# SQL-lite 

*IB DP first Project*

The repository contains SQL scripts and database documentation for Independent Project 1, created in October during the IB Diploma Programme Year 1. Designed entirely on my own, the project concentrates on structured data managementt, database designing using relations, and query optimization. The workspace contains well-structured code resources for schema creation, data manipulation, and relational tables that address a particular problem of structured data handling. The repository is used as a platform for version tracking of the database and for meeting the technical requirements of the IB curriculum framework.
